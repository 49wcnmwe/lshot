# LShot 截图定制实施记录

用户指定从 1003129155/jietuba fork，目标仓库 49wcnmwe/lshot，基线 0cac0e9c63f85e7679bcd118c46f1a398d3bf840（master2）。该指令替代此前从零编写 WPF 的技术选择，沿用上游 C++/Qt 与 Rust；已确认的交互与视觉要求继续有效。

## 已确认要求
薄荷白、少量绿色强调、半透明浮动工具栏；图标工具悬停显示说明；Ctrl+Shift+A 默认截图且可自定义；文字、马赛克、矩形、实心点、直线、箭头；颜色/透明度/线宽，矩形数值圆角与比例，箭头实线/虚线；截图数值比例/锁定缩放与数值圆角；设置编辑水印、截图一键添加；手动滚动自动拼接；保存 JPEG；红 × 取消、绿 √ 复制；自启动与托盘后台。

## 实施计划
1. 复用上游后台、热键、长图、水印和图像输出模块，修改 fork 默认快捷键、JPEG 格式及薄荷色板，保留 MIT 版权声明。
2. 增加共享比例几何；接入截图比例输入及锁定约束；矩形保存比例并在绘制、控制点调整及撤销重做中保持。
3. 为矩形参数面板增加可输入圆角/比例；截图圆角浮层增加数值输入；仅矩形显示额外属性。
4. 实心点替代椭圆默认绘制；直线单独入口；箭头线段样式接入参数、绘制、选中修改及历史。
5. 水印内容编辑加入设置页，复用当前持久化与一键添加路径。
6. 新增针对比例、圆角、线段及 UI 参数可见性的 QtTest，提交到 fork feature/mint-capture，并通过 Windows Actions 构建验证和上传运行包。云端流程不使用上游签名凭据、不宣称继承上游签名。

## 验证边界
本地 Windows 没有 MSVC/Qt/Rust 工具链，因此不把源码检查当成构建通过。Actions 的状态与产物另行记录；若 fork 尚未允许 Actions，需要仓库所有者启用。

## 使用方式

- 启动后按 Ctrl+Shift+A 框选区域。快捷键和开机自启动可在设置页调整；关闭主窗口后通过系统托盘继续使用。
- 区域上方可输入宽高比例，修改数值会锁定比例；取消锁定后恢复自由调整。圆角图标点击启用，悬停后可用数值框或滑块调整半径。
- 工具栏图标悬停显示说明，选中标注工具后下方浮出参数。矩形另有圆角、比例和锁定框；选中已画矩形可直接修改并撤销。按 Ctrl+Z 撤销，Ctrl+Y 重做。
- 设置的截图页可编辑水印内容，截图时点击水印图标直接插入。
- 长截图默认手动滚动：用户滚动目标页面，工具自动拼接；结束后在预览中确认。
- 红色 × 取消，绿色 √ 复制到剪贴板。保存图标打开保存窗口，默认 JPG/JPEG；透明圆角在 JPEG 中填为白色。
- Windows Actions 的 `lshot-windows-x64` 包含程序及依赖，请解压整个文件夹后运行其中的 exe。
